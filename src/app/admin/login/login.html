How to create a token
  1. Open GitHub’s new fine-grained token page (opens in a new tab) and pick an expiry date.
  2. Under Repository access, choose Only select repositories and select {{ repoName() }}.
  3. Under Repository permissions, set Contents and Actions to Read and write.
  4. Generate the token, copy it into your password manager, and paste it above.
